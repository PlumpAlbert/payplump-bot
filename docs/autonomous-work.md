# Автономный проход по оставшейся реализации

## Разрешения и границы

Владелец разрешил автономно продолжать код и тесты с субагентами
`openai-codex/gpt-6-luna`, reasoning `high`. Изменения идут отдельными PR;
самостоятельный squash merge разрешён только после успешных проверок точного HEAD.

Invoice Ninja и S-UI — **production с действующими пользователями**.
В этом проходе не обращаемся к установленным API даже для экспериментального
GET. Контракты изучаем по закреплённым публичным исходникам. HTTP-тесты работают
только с синтетическими loopback-серверами. Настоящие Telegram-доставки, платежи,
публикация образов, инфраструктурные изменения и запуск в Komodo запрещены.

БД доступна для изменений, но проверки всё равно используют отдельные схемы
с проверенным search_path и очисткой. Данные приложения и клиентов не нужны.
Секреты и реальные идентификаторы/конфигурации не попадают в Git, отчёты и логи.
`./scripts/test-safe.sh` очищает унаследованные параметры провайдеров и акторов,
оставляя только параметры подключения к БД; сам `.env` не читает.

Все новые effectful-функции выключены по умолчанию. Неизвестная внешняя запись
не переотправляется по истечении lease. Уже существующие барьеры/epoch,
проверка текущей оплаты, собственная provenance и private actor scope сохраняются.
Отдельные несогласованные writer-барьеры не допускаются.

## Рабочая очередь

- [ ] 8a: source-pinned disable / closeSessions, recurring pause / schedule / resume,
  GET-only discovery управляемых recurring-счетов, синтетические контракты.
- [ ] 8b: журнал периодов, новые счета, срок оплаты до конца дня,
  fresh-unpaid overdue workflow и отдельные подтверждения внешних шагов.
- [ ] 9: подтверждённая очередная/поздняя оплата, перенос даты до start,
  сохранение credentials/URL, гонки с отключением и исторические review.
- [ ] 10: приватная административная рассылка с неизменяемым подтверждением,
  снимком получателей, долговечным прогрессом и ограниченной доставкой.
- [ ] 11: контролируемый план/валидация и DB-only применение импорта,
  без автоматического предоставления effectful/URL capability и без live запуска.
- [ ] 12: безопасный отчёт неизвестных операций, инструкции и изолированные
  проверки backup/restore; никаких автоматических rearm/снятий барьеров.
- [ ] 13: release manifest, ручной opt-in build/publish workflow и Compose
  для запуска по digest; никаких реальных publish/deploy.
- [ ] 14: синтетический resource harness и данные измерений там, где реально
  выполнены; не выдавать показатели CI/локальной машины за измерения VPS.

Отметки ставятся после реальных проверок, не по результатам намерения агента.
Отчёт завершённого прохода перечислит PR, точные проверенные commits, результаты
и оставшиеся действия владельца.

## Остаётся владельцу

Проверка на выделенном клиенте и установленных версиях: полный платёжный цикл,
реальное отключение/разрыв сессий/восстановление, импорт и связь sing-box,
реальные webhooks/Telegram. Также рабочий импорт, внешние резервные копии,
restore/rollback инфраструктуры, целевые измерения VPS, публикация и Komodo.
Успешные исходники и синтетические тесты не заменяют эти испытания.
